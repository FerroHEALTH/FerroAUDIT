Owner decision 2026-10-19, final, the same for every FerroHEALTH product:

- Only the newest release is supported. An older release never receives a
  fix, backport or patch; the remedy is to upgrade, which is free.
- The CRA five-year minimum is a commitment for the product: Cadasto B.V.
  keeps publishing security fixes for at least five years after each release
  is placed on the market (Article 13(8)), delivered only in the version last
  placed on the market (Article 13(10)).

**Why:** "each release is supported for five years" read as a per-release
support promise the project does not keep.

**How to apply:** never write a per-release support period; use the shared
wording in `SECURITY.md` §Supported versions.
